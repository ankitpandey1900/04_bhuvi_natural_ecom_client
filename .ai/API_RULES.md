# API Rules

## Standards

- Use RESTful resource-oriented routes.
- Version APIs from the start.
- Validate requests with shared schemas.
- Return consistent error payloads.
- Enforce authentication and authorization at the boundary.
- Use pagination, filtering, sorting, and rate limiting where appropriate.

## Required Practices

- Keep route handlers thin.
- Put business logic in services.
- Use shared validation and response formatting.
- Do not bypass security or permission checks.
- Document changes to endpoints and payloads.
