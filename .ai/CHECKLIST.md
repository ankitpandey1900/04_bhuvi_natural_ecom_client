# Engineering Checklist

## Before Completing a Task

- [ ] Existing patterns and files were reviewed.
- [ ] The change follows the documented architecture and playbook.
- [ ] Type safety and validation are preserved.
- [ ] Accessibility, SEO, and performance were considered.
- [ ] Security requirements were respected.
- [ ] Relevant tests and documentation were updated.
- [ ] The work is reviewable and consistent with the design system.

## Before Raising a PR

- [ ] Linting and type checks pass.
- [ ] Relevant tests pass.
- [ ] Documentation is updated where needed.
- [ ] No secrets or sensitive data were introduced.
- [ ] The change is scoped and understandable.
