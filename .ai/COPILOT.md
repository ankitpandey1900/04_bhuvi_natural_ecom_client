# GitHub Copilot Rules

## Working Style

- Prioritize existing patterns and shared abstractions.
- Make the smallest correct change that solves the task.
- Respect the product and design system boundaries.

## Engineering Expectations

- Do not create duplicate components, hooks, utilities, or validation schemas.
- Preserve type safety, tests, accessibility, SEO, and security.
- Follow the project folder structure and naming conventions.
- Keep changes aligned with the architecture and roadmap.
