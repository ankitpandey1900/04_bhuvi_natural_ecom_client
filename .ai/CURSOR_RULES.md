# Cursor Rules

## Project Guardrails

- Follow the approved architecture and implementation plan.
- Reuse existing design-system and component patterns.
- Respect folder conventions and module boundaries.
- Keep business logic out of components and route handlers.
- Prefer server-rendered solutions for public pages.

## Required Checks

- Check for existing implementations before creating new ones.
- Keep TypeScript strict and explicit.
- Maintain accessibility and responsive behavior.
- Preserve SEO, performance, and security expectations.
- Update tests and docs alongside behavior changes.
