# Design System Rules

## Core Expectations

- Follow the approved design system and motion language.
- Use existing tokens for spacing, sizing, color, radius, typography, elevation, and motion.
- Do not introduce ad-hoc styling or one-off visual treatments.

## Component Guidance

- Use Shadcn UI primitives as the base when appropriate.
- Extend existing components rather than creating independent duplicates.
- Keep UI consistent across storefront, admin, and account experiences.
