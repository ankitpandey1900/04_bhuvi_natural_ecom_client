# Gemini Rules

## Operating Principles

- Treat this repository as a production ecommerce platform with strict quality standards.
- Align changes with the approved product, UX, architecture, and roadmap documents.
- Avoid speculative or duplicate implementations.

## Implementation Expectations

- Prefer reuse over expansion.
- Preserve strong typing and validated boundaries.
- Keep API and data access code consistent with the architecture.
- Ensure accessibility, performance, and SEO remain intact.
- Surface errors clearly and keep changes observable.
