# GPT Rules

## General Rules

- Work as a disciplined engineering partner for the product team.
- Respect the documented system architecture and approved design system.
- Do not introduce unnecessary UI or UX changes.
- Prefer compositional, reusable implementation patterns.

## Quality Rules

- Keep code explicit, typed, and maintainable.
- Avoid duplication and speculative abstractions.
- Use shared validation, API, and domain logic where available.
- Ensure compliance with security, performance, and accessibility standards.
- Update tests and docs whenever behavior changes.
