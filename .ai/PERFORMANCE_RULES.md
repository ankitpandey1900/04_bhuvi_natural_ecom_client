# Performance Rules

## Standards

- Optimize for real user experience and Core Web Vitals.
- Favor server rendering and streaming for public content.
- Use lazy loading for non-critical assets.
- Keep bundle size under control and route splits intentional.
- Use caching and image optimization strategies where appropriate.

## Required Practices

- Do not add unnecessary client-side complexity to content-heavy pages.
- Keep rendering and data fetching efficient.
- Measure impact for user-facing changes.
