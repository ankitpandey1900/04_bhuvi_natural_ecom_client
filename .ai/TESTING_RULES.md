# Testing Rules

## Standards

- Add or update tests when behavior changes.
- Use unit tests for utilities and isolated logic.
- Use integration tests for API and module behavior.
- Use end-to-end tests for critical customer and admin journeys.
- Validate accessibility and performance for user-facing changes.

## Required Practices

- Do not ship a change without relevant test coverage where practical.
- Preserve regression safety around checkout, auth, payments, and inventory flows.
