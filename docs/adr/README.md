# Architectural Decision Records

This directory contains Architecture Decision Records for the Bhuvi Naturals ecommerce platform.

## ADR Index

- ADR-001: Use Next.js as the primary frontend and application framework
- ADR-002: Use Better Auth for authentication and session management
- ADR-003: Use PostgreSQL as the primary relational database
- ADR-004: Use Prisma as the ORM and database toolkit
- ADR-005: Use Razorpay for payments and order capture
- ADR-006: Use Cloudinary for media storage and optimization
- ADR-007: Use Vercel for deployment and hosting
- ADR-008: Use Tailwind CSS for styling
- ADR-009: Use Shadcn UI for component primitives
- ADR-010: Use Framer Motion for animation and interaction polish
